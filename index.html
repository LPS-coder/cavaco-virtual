SOBRE O PROJETO

Cavaco Virtual

Uma ferramenta interativa para explorar o braço do cavaquinho brasileiro, visualizar notas e reproduzir gravações reais do instrumento.

Nesta primeira versão, a interface e o cálculo das notas estão funcionais. Para ouvir o timbre real, adicione as gravações WAV indicadas no arquivo README.
